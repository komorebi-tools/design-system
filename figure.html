1. 三層構造

色は3つの層でできている。 Layer 1 は固定、Layer 2 は案件ごとに差し替え可、Layer 3 は意味が決まっている。 グレーはどの層にも属さない下地として分けて扱う。

1.1 Layer 1 : ブランド基調

既存トークンをそのまま使う。 図表のために新しい色を足さない。 数値は白文字を乗せたときのコントラスト比。

Primary と Primary Dark は使い分ける。 面 ( 見出し帯 ･ 表のヘッダ ･ カードの帯 ) には Primary、グラフの主色 ･ pill ･ グラデーションの起点には Primary Dark。 一本化しないのは、従来のスライドがすでにこの2値で運用されていたため。 2つは ΔE 7.3。
ゴールドで白文字を乗せるなら SUB。 Accent 2.37 ･ Accent Dark 2.99 に対して SUB は 3.18 で、この色だけが条件を満たす。 Accent はグラフの系列に使い、白文字は乗せない。

1.2 Layer 2 : カテゴリ配色

面 ･ 地 ･ マーカー ･ 文字 の4値でひと組。 面色がひとつ決まれば、残り3つは計算で出せる。 1案件あたり4色まで ( 定番は5色、そこから選ぶ )。

4値の導き方。 地 ＝ 面を白 90% で薄める / マーカー ＝ 地の上に面を不透明度 30% / 文字 ＝ 彩度 ×1.35、黄系のみ色相 −15°、明度は白背景比 3.0 に届くまで下げる。

白文字を乗せる面には「文字色」を敷く

pill ･ 見出し帯 ･ 番号カードのように白文字を乗せる面は、面 ( fill ) ではなく文字の色を面として使う。

面をそのまま敷く

文字色を面として敷く

面をそのまま敷くと CAT-4 山吹が 1.87 で選定条件 B ( 2.0 以上 ) を割る。 文字色を敷けば5色とも 2.99 〜 3.75 に揃い、色ごとの見え方の差もなくなる。 淡い面を使うのは「文字を乗せない」場面 ( タイルの地、グラフの系列、マーカー ) に限る。

1.3 グレーは実運用の5段から使う

値を新しく作らない。 スライド本体で 50 回以上使われている5段だけを使う。 値は固定しすぎず、図ごとにトーンが揺れることは許容する。

守ること下限
文字に使うグレー本文サイズなら比 4.5 以上 ( #767676 まで )、大きめの太字なら 3.0 以上 ( #888888 まで )
面 ･ 罫線 ･ 非強調の系列白と見分けがつくこと ＝ 比 1.2 以上
段として並べるとき隣り合う段を ΔE 4 以上離す
例外読ませない意図の文字 ( 弱い群 ) は比 3.0 を割ってよい。 1つの図に1役割まで
#999999( 2.85 ) と #B7B7B7( 2.01 ) は文字の基準を割っているが、どちらも「読ませない」ことが目的の役割なので例外に当たる。 #595959 と #666666 は ΔE 4.8 と近いので、同じ図の中で両方を段として使わない。

線は表の枠線だけにする

スライド本体で線の指定を数えると、枠線なし ( noFill ) が 1,241 件で圧倒的。 図形には引かず、面と余白で形をつくる。

Border #E0E0E0 は「面」としても残す ( 非強調の系列 ･ ドーナツのトラック )。 角丸そのものは可。 ただし角を丸めるほど Web UI に見えるので、KPIカードのような面の大きい要素では積極的には使わない。

1.4 Layer 3 : 強調

案件で変わらない唯一の色。 カテゴリの識別には使わない。 1スライドにつき1箇所を原則とする。

面ではなく文字色として使うほうが、面積が小さく済み意味が立つ。 Point #CD5151 は Danger #D9534F と ΔE 3.0 で見た目はほぼ同じだが、意味が違う。 Danger はエラー ･ 削除 ･ 危険な操作、Point は注目の誘導。 名前は必ず分けて使う。

1.5 色に意味を持たせるときの判断

色そのものではなく、色のどの軸が何を担うかを決める。

軸担うもの
濃さ量 ･ 強弱 ･ 順序
色相順序のないカテゴリの識別
無彩色値ではないもの ( 比較対象 ･ 非該当 ･ 見出し )
そのうえで、次の順に見る。
1. データにカテゴリがあり、その意味が資料全体で一貫するときだけ色相を分ける
2. 順序 ･ 量 ･ 強弱は色相ではなく濃さで示す
3. 慣習の色 ( 赤 = 危険、緑 = 良い ) は、同じ資料に警告や正負の表現が無いときだけ使う
4. 1つの資料の中で、同じ色を2つの意味に使わない
実務でいちばん効くのは 4。 ヒートマップの塗りを表ごとに変えないのも、2群の色を資料内でそろえるのも、理由はここにある。

2.9 コレスポンデンス分析 ･ 散布図

    
種類が違うものは色だけでなく形も変える。
    ブランドは Primary Dark の丸、項目は Accent の菱形。

    

    

    

      縦横比は固定する。ブラウザ幅やスライドサイズで変えない。
      開くたびに比率が変わると、同じ図が違う印象になる。
      距離を読ませるなら 1 : 1、偏りを見せるなら1次元、見慣れた散布図で出すなら縦を伸ばしてよいが軸ラベルに「縦の差は読まない」と書く。
      第1軸の寄与率が 90% を超えているときは実質1次元なので、1次元に落とすほうが順序と距離がそのまま読める。

      ラベルは、右 → 左 → 上 → 下 の順に空いている側を探して逃がす。
      重なりは機械で消し、手で動かさない。

2.12 強調と非強調

    
読ませたいものだけ色を残し、残りは無彩色に寄せる。
    色を足して強調をつくらない。
    この考え方は図の種類を問わない。

    

    

      
段数値隣り合う ΔE

      
        
3段まで#C4C4C4 #D8D8D8 #ECECEC4.8 / 4.4

        
4段#B7B7B7 #C9C9C9 #DBDBDB #EDEDED4.6 / 4.3 / 4.0

      
    

    

      無彩色を段に分けるのは、残りに順序があるときだけ。横棒や散布図のように残りが並列なら1色でよい。
      ドーナツや積み上げ棒のように順序が残るなら段にする。

      起点が濃すぎると、残りが「弱めた主役」ではなく「もうひとつの主役」に見える。#999999 から始めると、残りの段のうち上2段が主役級の重さになる。

      色以外も一段変える。面 ( 棒 ･ セル ･ 扇形 ) は色だけでよいが、線と点は面積が小さいので太さと大きさも一段変える。

      グレーの値は図ごとに変えてよい ( §1.3 )。
      段として並べるときだけ、隣り合う段を ΔE 4 以上離す。

3. 見出しの階層

  
階層は線ではなく、面 ･ 余白 ･ 文字サイズ ･ 番号 で作る。
  色帯を1本足しても段は増えない。


  

    
3.1 作り方

    
上ほど強い。
    ただし目安なので、どの段にどれを当てるかは資料ごとに決めてよい。

    

      
01
左に番号を置き、地を薄青で塗る

      
地 #F3F7FC。
      いちばん強い段。
      1画面に1つか2つまでにする。


      
見出しの下に全幅の細罫を引く

      
罫は #E0E0E0 ･ 0.75pt。
      線を引くならこの形にする。
      見出しごとに色の違う線を引かない。


      
青字 ＋ マーカー ＋ 太字

      
文字 #5A74A3、マーカー #C9D3E4。
      カテゴリを割り当てていない資料の強調は、このマーカーを既定にする。


      
青字 ＋ 太字

      
いちばん軽い段。#5A74A3 は白背景比 4.71 で、本文サイズでも読める。


      
基準のグレー ＋ 太字 ( 例外 )

      
近くでマーカーを使っていて見出しと区別がつかないときは、本文色の太字に落としてよい。
      スライドは #434343、HTML は #333333。

   

    

      Primary #6E87B6 は白背景比 3.62 で本文サイズに届かないため、見出しの文字色には使わない。 
      面には Primary、見出しの文字には Primary Dark。
   

 


  

    
3.2 左の色帯

    
見出しの左に色帯を敷くのは、スライドテンプレートに元からある縦棒 ( タイトル左 #7288B2 ) だけとする。
    これは版面の一部で、装飾ではない。

    

      

        
使わない : カードごとに反復する色帯

        

          
カードごとに同じ左3pxの帯がある
帯が情報を持っていない

          
カードごとに同じ左3pxの帯がある
消しても意味が変わらない

          
カードごとに同じ左3pxの帯がある
5つ目の合図として重複している
